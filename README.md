File System Representation and Search Using BFS and DFS

Project Description

This project represents a file system as a graph using an adjacency matrix. It implements Breadth-First Search (BFS) and Depth-First Search (DFS) to traverse the graph and search for a specific file or directory.

Objectives

- To represent a file system using a graph.
- To implement BFS traversal.
- To implement DFS traversal.
- To search for a specific file or directory.

Technologies Used

- Programming Language: C
- Data Structure: Graph
- Graph Representation: Adjacency Matrix
- Algorithms: BFS and DFS

Algorithm

1. Read the number of files and directories.
2. Enter the names of the files and directories.
3. Create the graph using an adjacency matrix.
4. Perform BFS traversal from the starting node.
5. Perform DFS traversal from the starting node.
6. Search for the target file or directory.
7. Display the traversal results and search status.

Sample Output

BFS Traversal: Root Documents Pictures Notes Photo
DFS Traversal: Root Documents Notes Pictures Photo
File/Directory 'Photo' is FOUND.

Result

The file system was represented using a graph, and BFS and DFS were implemented successfully. The program traverses the graph and searches for the specified file or directory.
